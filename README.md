# Hobbly — Booking and Payment Vertical Slice

Private, lightweight evidence repository for a validated portfolio prototype.

## Reproduce

```bash
make setup
make test
make reproduce
make docs
```

The prototype uses synthetic listings, slots, users and payment responses. no real payment credentials, personal data or regulated funds flow. Its results are technical evidence, not a claim of production deployment or client impact. Start with `docs/DOSSIER.md` and verify `artifacts/evidence-manifest.json`.
